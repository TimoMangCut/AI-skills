# Phase 1.1 Micro-Skill: Codebase & Convention Scout (`codebase_scout`)

Bạn đang thực thi **Micro-Skill `phase-1-codebase-scout` (Bước 1.1)** trong bộ kỹ năng **LocalSec v3.0**.
Mục tiêu của bước này là **tiết kiệm chi phí (usage) nhưng định vị chính xác mẫu số kiểm toán** trước khi quyết định dùng Python helper hay đọc sâu: AI chỉ nhìn cấu trúc thư mục (`list_dir`) và đọc lướt 3–5 file mẫu (`read_file`) để hiểu **cách team tổ chức code**, phân loại **Product Archetype**, xếp hạng **Repo Tier (1/2/3)** và khóa **Target Modules Map**.

---

## 1. Quy tắc Kỷ luật Bắt buộc (Strict Micro-Skill Budget)

1. **Giới hạn ngân sách khám phá sơ bộ**:
   - Tối đa `3–5` lệnh `list_dir` (dùng `--depth 2` ở thư mục gốc và các thư mục `src/`, `app/`, `cmd/`, `internal/`, `packages/`, `deploy/`).
   - Tối đa `3–5` lệnh `read_file` trên các file mẫu đại diện:
     - 1 file manifest/build (`package.json`, `go.mod`, `pom.xml`, `build.gradle`, `Cargo.toml`, `CMakeLists.txt`, `pyproject.toml`, `pubspec.yaml`, `AndroidManifest.xml`).
     - 1 file bootstrap/router/wiring chính (`main.go`, `app.module.ts`, `urls.py`, `Program.cs`, `server.ts`, `main.cpp`).
     - 1–2 file controller/handler/consumer mẫu để biết cách team viết route, middleware/decorator xác thực và truy cập dữ liệu.
2. **Không phân tích lỗ hổng ở bước này**: Chỉ lập bản đồ cấu trúc và quy ước code.
3. **Mọi thư mục bỏ qua (`ignored_modules`) BẮT BUỘC phải có lý do (`reason`)**: Ví dụ `vendor/`, `node_modules/`, `dist/`, `migrations/autogenerated`, `mock_fixtures/`. Các thư mục nằm trong `target_modules` sẽ được **Visibility Tracker** giám sát độ phủ vật lý ở Bước 1.6.

### 2.2. Phân hạng Repo Tier (Adaptive Cost-Efficiency)
- **`tier_1` (Critical Production / Safety / Core Auth / Financial / Gateway / OT Control)**: Cần đọc sâu đầy đủ và kiểm chứng mọi bất biến S-F-O-P-C.
- **`tier_2` (Standard Internal Backend / B2B Service / Data Pipeline / Supporting App)**: Tập trung vào trust boundary, authz, đầu vào/đầu ra nhạy cảm.
- **`tier_3` (Static UI Library / SDK Wrapper / Documentation / Prototype / Test Utility)**: Chế độ khảo sát nhẹ (Lightweight Recon), kiểm tra hardcoded secrets, dependency/supply-chain và cấu hình.

## 3. Giao thức Thực thi CLI

```bash
# 1. Xem cấu trúc thư mục gốc (depth 2)
python3 -m localsec.manual_session list_dir <repo_name> . --depth 2 --skill codebase_scout

# 2. Đọc 3-5 file mẫu để xác định quy ước code (routing, auth decorator, ORM/IPC)
python3 -m localsec.manual_session read_file <repo_name> <path_to_sample_file> 1 120 --skill codebase_scout

# 3. Lưu và xác thực kết quả codebase_scout.json
python3 -m localsec.manual_session register_scout_map <repo_name> /tmp/codebase_scout_<repo_name>.json
```
